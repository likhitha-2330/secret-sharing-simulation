# Secret Sharing Simulation

A static interactive demonstration that visualizes secret sharing concepts (Shamir-style or similar) using HTML/CSS/JS.

## What it is
- Front-end only project (HTML, CSS, JS)
- Demonstrates how a secret is split into shares and reconstructed from a subset of shares
- Useful as an educational tool or demo

## How to run
- Clone the repo and open `index.html` in your browser:
  git clone https://github.com/likhitha-2330/secret-sharing-simulation.git
  cd secret-sharing-simulation
  # open index.html with your browser (double-click or `open index.html`)

- Or start a simple local server (Python):
  python -m http.server 8000
  open http://localhost:8000
